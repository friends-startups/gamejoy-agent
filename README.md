# GameJoy Agent

GameClass klub dasturi uchun [kompyuterxona.uz](https://kompyuterxona.uz) agenti. Klub serverida GameClass bazasini faqat o'qiydi va kompyuterlar holatini (bo'sh / band) kompyuterxona.uz ga yuboradi.

Bu repoda faqat tayyor fayl (`GameJoyAgent.exe`) release sifatida turadi.

## O'rnatish

1. [GameJoyAgent.exe](https://github.com/friends-startups/gamejoy-agent/releases/latest/download/GameJoyAgent.exe) ni yuklab oling.
2. GameClass o'rnatilgan kompyuterda o'ng tugma → **Administrator sifatida ishga tushiring**.
3. Kabinetdagi (biznes.kompyuterxona.uz → GameClass integratsiya) 8 belgili ulash kodini kiriting.

Talablar: Windows 10 / Windows Server 2016 yoki yangisi, 64-bit. Faylni faqat shu repo yoki kompyuterxona.uz kabinetidan yuklab oling; `SHA256SUMS.txt` bilan tekshirishingiz mumkin.

Buyruqlar: `GameJoyAgent.exe status`, `GameJoyAgent.exe uninstall`, `GameJoyAgent.exe --help`.
